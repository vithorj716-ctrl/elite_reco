# Enchanted Interfaces

A partir deste momento siga obrigatoriamente estas regras em todas as telas novas e existentes.

NÃO criar interfaces com aparência de template de IA.

Evite:

- cards genéricos

- muito espaço vazio

- layouts excessivamente simétricos

- tudo centralizado

- botões enormes

- componentes padrão do shadcn sem personalização

- excesso de bordas arredondadas

- sombras exageradas

- azul padrão do Tailwind

Sempre utilizar:

✓ Motion para microinterações

✓ GSAP quando houver animações mais elaboradas

✓ ScrollTrigger para seções especiais

✓ Lenis para scroll suave

✓ animações suaves entre páginas

✓ stagger animation em listas

✓ hover com feedback visual

✓ botões com efeito de pressão

✓ carregamentos com skeleton

✓ estados vazios elegantes

✓ loading profissional

✓ transições de modal

✓ animações reversíveis ao voltar o scroll

Todas as animações devem possuir easing profissional e duração entre 200ms e 700ms conforme o contexto.

Nunca usar animações chamativas ou exageradas.
